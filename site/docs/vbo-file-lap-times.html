How to get lap times from a VBO file

VBO (.vbo) is the file a Racelogic VBOX writes, and most lap-timer apps can export it, RaceChrono, TrackAddict and Harry's LapTimer among them. Track Evolution turns a VBO file into a session with lap times, a racing line and whatever car data the file logged. The file is read on your own computer or phone.

What you need

  • A .vbo file for each session.
    • From a Racelogic VBOX: the files on its SD card.
    • From RaceChrono, TrackAddict or Harry's LapTimer: export the session in VBO format.
    • From Porsche Track Precision: see its own page.
  • A free Track Evolution account, on the web at trackevolution.app or in the iPhone or Android app.

In the browser

  1. Open the event at trackevolution.app, or start a New event.
  2. Press Import video / telemetry… and choose the .vbo files, or drag them onto the box. Each file becomes its own session.
  3. If the review shows a track map with no laps, click where the start/finish line is. One click covers every file in the import.
  4. Check the laps, then save.

On your phone

  1. Save the .vbo file to Files on the phone. A lap-timer app's export can go straight there.
  2. Open the event in the Track Evolution app, tap Import video and pick the file from Files.
  3. Tap the start/finish line if the review asks for it, check the laps, and save.

Where the lap times come from

When the file names a start/finish line, laps are timed on it with nothing to set. When it doesn't, you pick the line on the map of the track you drove. See the start/finish line picker.

A lap is timed between the GPS positions either side of the line, so the times carry a ~. A 10 Hz or faster logger puts each lap within a tenth or two of a second.

What you get

  • Lap times for every full lap, and the session's best.
  • Your racing line for the best lap, as a track map.
  • A speed graph for every lap, overlaid by distance around the track.
  • Car data, when the file logged it: RPM, throttle, brake, steering, cornering and braking force, gear and tire pressures. A logger wired to the car, or a lap-timer app with an OBD reader, records some of these; a GPS-only file has speed alone.

What is free and what is Pro

  • Free, with no limit on files: importing, the lap times, the racing line, and the speed, throttle and brake graphs for every lap.
  • Track Evolution Pro ($1.99 a month or $19.99 a year): the other graphs, sector splits and a theoretical best lap, and lap-against-lap time deltas.

A VBO file has no video, so there is no best-lap video to save.

If it doesn't work

  • "VBO file contains no usable GPS data". The device had no GPS position while it recorded. Next time, give it a clear view of the sky and a few minutes before the session.
  • "Not a valid VBO file" or "VBO file is missing time/lat/long columns". The export isn't in VBO format, or left out position. Export again and choose VBO.
  • "No laps cross the picked line". Click a part of the track the car drove on every lap.
  • No throttle or brake graph. The file didn't log them. Only speed comes from GPS.
